# Sitio Web de Herramientas - Tienda Online

Este proyecto es una página web / landing page interactiva desarrollada para la presentación y comercialización de herramientas de trabajo y jardinería (hachas, machetes y combos de palas).

## 🚀 Características del Proyecto

- **Estructura Semántica:** Construido con etiquetas semánticas de HTML5 (`header`, `nav`, `main`, `section`, `footer`).
- **Navegación Interna:** Menú con lista desordenada y enlaces para desplazarse fácilmente por la página.
- **Diseño Responsivo:** 
  - **Flexbox:** Organiza la sección de productos en tarjetas (*cards*) adaptables.
  - **CSS Grid:** Distribuye la sección de reseñas de forma limpia y estética.
  - **Media Queries:** Adapta la navegación y el formulario para dispositivos móviles.
- **Formulario de Contacto Funcional:** Integrado con [Formspree](https://formspree.io/) para procesar el envío de mensajes.
- **Estilos Personalizados:** Tipografía integrada mediante Google Fonts y diseño visual mediante CSS externo (`styles.css`).

## 🛠️ Tecnologías Utilizadas

- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Media Queries)
- **Google Fonts**
- **Formspree**
